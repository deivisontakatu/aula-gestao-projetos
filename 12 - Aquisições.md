# 1️⃣ O que são aquisições?

As **aquisições** representam o processo de obter produtos, serviços ou resultados de fontes externas ao projeto.

Nem todos os recursos necessários precisam ser produzidos pela própria organização.

### 🛒 Exemplos

| Aquisição | Utilização |
|---|---|
| 💻 Computadores | Infraestrutura |
| ☁️ Servidor | Hospedagem |
| 🛠️ Software | Desenvolvimento |
| 👨‍💻 Serviço especializado | Atividade técnica |
| 🏢 Espaço | Execução do projeto |
| 📦 Equipamentos | Produção |
| 🛡️ Serviço de segurança | Proteção |

### 💡 Exemplo

Uma empresa está desenvolvendo um aplicativo.

A equipe possui desenvolvedores, mas não possui profissionais especializados em segurança.

Nesse caso, pode ser necessário contratar uma empresa especializada.

---

# 2️⃣ Gerenciamento das aquisições

O **gerenciamento das aquisições** envolve planejar, realizar e controlar as compras e contratações necessárias para o projeto.

### 📋 Principais atividades

| Atividade | Finalidade |
|---|---|
| 📋 Planejamento | Identificar o que precisa ser adquirido |
| 🔎 Pesquisa | Identificar possíveis fornecedores |
| 📄 Solicitação | Solicitar propostas |
| 🤝 Negociação | Definir condições |
| 📝 Contratação | Formalizar o acordo |
| 📊 Controle | Acompanhar o contrato |
| 🏁 Encerramento | Finalizar a aquisição |

---

# 3️⃣ Planejamento das aquisições

O planejamento das aquisições busca definir **o que será comprado, quando será necessário, como será contratado e quem será responsável**.

### 📋 Perguntas importantes

- O que precisa ser adquirido?
- Por que precisa ser adquirido?
- Quando será necessário?
- Qual quantidade?
- Qual especificação?
- Quanto poderá custar?
- Existem fornecedores disponíveis?
- Quem será responsável pela contratação?
- Como o fornecedor será avaliado?

### 💡 Exemplo

Um projeto precisa contratar um serviço de hospedagem.

| Elemento | Definição |
|---|---|
| ☁️ Produto | Serviço de hospedagem |
| 📅 Necessidade | Durante o desenvolvimento |
| 💰 Orçamento | R$ 5.000 |
| 📋 Requisito | Alta disponibilidade |
| 🔐 Segurança | Certificados e proteção |
| 👤 Responsável | Equipe de infraestrutura |

---

# 4️⃣ Fazer ou comprar?

Uma decisão importante nas aquisições é determinar se determinado produto ou serviço será desenvolvido internamente ou obtido externamente.

Essa análise é conhecida como:

> **Fazer ou comprar?**

### 📊 Comparação

| Fazer | Comprar |
|---|---|
| 👥 Utiliza equipe interna | 🛒 Utiliza fornecedor |
| 🧠 Maior controle interno | 🎯 Pode utilizar especialização externa |
| ⏱️ Pode exigir mais tempo | 🚀 Pode acelerar a execução |
| 💰 Pode exigir recursos internos | 💰 Possui custo de contratação |

### 💡 Exemplo

Uma empresa precisa desenvolver uma identidade visual.

Ela pode:

**Fazer:** utilizar seu próprio designer.

**Comprar:** contratar uma agência especializada.

A decisão deve considerar custos, prazo, competências, riscos e necessidades do projeto.

---

# 5️⃣ Análise de fazer ou comprar

A decisão não deve considerar apenas o preço.

### 📊 Fatores importantes

| Fator | Pergunta |
|---|---|
| 💰 Custo | Qual alternativa possui melhor relação de custos? |
| ⏱️ Prazo | Qual alternativa permite entregar mais rapidamente? |
| 🧠 Competência | A organização possui conhecimento necessário? |
| ⭐ Qualidade | Qual alternativa atende melhor aos requisitos? |
| ⚠️ Risco | Qual alternativa apresenta menor exposição? |
| 🔐 Controle | Quanto controle será necessário? |
| 📈 Estratégia | A atividade é estratégica para a organização? |

### 💡 Exemplo

Uma organização pode contratar um serviço mais caro porque não possui a competência necessária internamente.

Nesse caso, o custo não é o único fator da decisão.

# 6️⃣ Fornecedores

Os **fornecedores** são organizações ou profissionais externos que fornecem produtos, serviços ou resultados para o projeto.

### 👥 Exemplos

- 🏢 Empresas;
- 👨‍💻 Consultores;
- 🛠️ Prestadores de serviço;
- ☁️ Empresas de tecnologia;
- 📦 Distribuidores;
- 🏭 Fabricantes.

### 💡 Exemplo

Um projeto de infraestrutura pode possuir:

| Fornecedor | Serviço |
|---|---|
| ☁️ Empresa A | Hospedagem |
| 🛡️ Empresa B | Segurança |
| 💻 Empresa C | Equipamentos |
| 🔧 Empresa D | Manutenção |

---

# 7️⃣ Pesquisa de fornecedores

Antes de contratar, a organização pode pesquisar possíveis fornecedores.

### 🔎 Informações importantes

- Experiência;
- Capacidade técnica;
- Preço;
- Prazo;
- Qualidade;
- Reputação;
- Garantias;
- Condições de pagamento;
- Capacidade de atendimento.

### 💡 Exemplo

Uma organização identifica três fornecedores:

| Fornecedor | Preço | Prazo | Experiência |
|---|---:|---:|---|
| A | R$ 20.000 | 30 dias | Alta |
| B | R$ 17.000 | 45 dias | Média |
| C | R$ 23.000 | 20 dias | Alta |

A escolha deve considerar os critérios definidos para o projeto.

---

# 8️⃣ Documentos de aquisição

Documentos de aquisição ajudam a comunicar aos fornecedores o que está sendo solicitado.

### 📄 Exemplos

| Documento | Utilização |
|---|---|
| 📋 Especificação | Define o que será adquirido |
| 📄 Solicitação de proposta | Solicita propostas aos fornecedores |
| 💰 Solicitação de cotação | Solicita preços |
| 📝 Termo de referência | Descreve necessidades e condições |
| 📑 Contrato | Formaliza o acordo |

### 💡 Exemplo

Uma empresa precisa contratar o desenvolvimento de um sistema.

O documento pode especificar:

- Funcionalidades;
- Tecnologias;
- Prazo;
- Critérios de qualidade;
- Entregas;
- Suporte;
- Condições de pagamento.

---

# 9️⃣ Propostas dos fornecedores

Os fornecedores podem apresentar propostas contendo informações sobre como pretendem atender à necessidade.

### 📊 Uma proposta pode apresentar

- 💰 Preço;
- 📅 Prazo;
- 🧠 Equipe;
- 🛠️ Solução;
- ⭐ Qualidade;
- 🛡️ Garantias;
- 📋 Condições;
- 📑 Experiência.

### 💡 Exemplo

| Critério | Fornecedor A | Fornecedor B |
|---|---:|---:|
| Preço | R$ 30.000 | R$ 25.000 |
| Prazo | 60 dias | 90 dias |
| Experiência | Alta | Média |
| Garantia | 12 meses | 6 meses |

A análise deve considerar todos os critérios relevantes.

# 🔟 Seleção de fornecedores

A seleção consiste em avaliar as propostas e escolher o fornecedor que atende aos critérios definidos.

### 📋 Critérios possíveis

- 💰 Preço;
- ⭐ Qualidade;
- ⏱️ Prazo;
- 🧠 Experiência;
- 🛠️ Capacidade técnica;
- 🛡️ Garantia;
- 📞 Suporte;
- ⚠️ Riscos.

### 💡 Exemplo

Uma organização pode utilizar uma matriz de avaliação:

| Critério | Peso | Fornecedor A | Fornecedor B |
|---|---:|---:|---:|
| Preço | 30% | 8 | 9 |
| Qualidade | 30% | 9 | 7 |
| Prazo | 20% | 8 | 6 |
| Experiência | 20% | 9 | 7 |

Os pesos permitem considerar a importância relativa de cada critério.

# 1️⃣1️⃣ Negociação

A negociação busca estabelecer condições adequadas entre comprador e fornecedor.

Podem ser negociados:

- 💰 Preço;
- 📅 Prazo;
- 📦 Entregas;
- 💳 Pagamento;
- 🛡️ Garantias;
- 🧰 Suporte;
- 📋 Responsabilidades;
- ⚠️ Penalidades;
- 🔄 Alterações.

### 💡 Exemplo

Fornecedor apresenta:

**R$ 50.000**

O comprador pode negociar:

- Pagamento parcelado;
- Prazo de entrega;
- Garantia;
- Suporte;
- Condições de manutenção.

A negociação deve buscar condições claras para as partes.

---

# 1️⃣2️⃣ Contratos

O **contrato** formaliza o acordo entre o comprador e o fornecedor.

Ele pode definir:

- 📋 Escopo;
- 📦 Entregas;
- 💰 Preço;
- 📅 Prazo;
- 🛡️ Garantias;
- 👥 Responsabilidades;
- 💳 Pagamento;
- ⚠️ Penalidades;
- 🔄 Alterações;
- 🏁 Encerramento.

### 💡 Exemplo

Um contrato de desenvolvimento de software pode estabelecer:

> O fornecedor deverá entregar o sistema em até 90 dias, seguindo os requisitos definidos e os critérios de aceitação estabelecidos.

O contrato cria uma referência para acompanhar a execução.

---

# 1️⃣3️⃣ Tipos de contratos

Os contratos podem distribuir os riscos financeiros de diferentes maneiras.

### 📊 Principais tipos

| Tipo | Característica |
|---|---|
| 💰 Preço fixo | Valor definido para o trabalho |
| ⏱️ Tempo e material | Pagamento conforme horas e materiais |
| 📊 Custos reembolsáveis | Custos são reembolsados conforme condições estabelecidas |

### 💡 Exemplo

**Preço fixo:**

> Desenvolvimento do sistema por R$ 50.000.

**Tempo e material:**

> R$ 150 por hora de desenvolvimento.

**Custos reembolsáveis:**

> Custos elegíveis são reembolsados conforme as condições contratuais.

---

# 1️⃣4️⃣ Contrato de preço fixo

No contrato de **preço fixo**, o valor é definido antecipadamente para o trabalho contratado.

### 💡 Exemplo

Uma empresa contrata:

> Desenvolvimento de website por **R$ 20.000**.

O contrato estabelece:

- Escopo;
- Entregas;
- Prazo;
- Critérios de aceite;
- Valor.

### 📊 Características

| Elemento | Característica |
|---|---|
| 💰 Preço | Definido |
| 📋 Escopo | Precisa estar claro |
| ⚠️ Risco | Pode existir para o fornecedor |
| 🔄 Mudanças | Podem exigir alteração contratual |

---

# 1️⃣5️⃣ Contrato por tempo e material

Nesse modelo, o pagamento está relacionado ao tempo utilizado e aos materiais ou recursos consumidos.

### 💡 Exemplo

Um consultor cobra:

**R$ 200 por hora.**

Se trabalhar:

**100 horas**

Então:

**Custo = 100 × R$ 200**

**Custo = R$ 20.000**

### 📊 Característica

Esse tipo de contrato pode ser utilizado quando o trabalho precisa de flexibilidade ou quando o escopo não está completamente definido.

---

# 1️⃣6️⃣ Administração dos contratos

Após a contratação, o contrato precisa ser acompanhado.

O objetivo é verificar se fornecedor e organização estão cumprindo as condições estabelecidas.

### 📊 O que acompanhar?

- 📦 Entregas;
- 📅 Prazos;
- 💰 Pagamentos;
- ⭐ Qualidade;
- 📋 Requisitos;
- 🛡️ Garantias;
- ⚠️ Problemas;
- 🔄 Mudanças.

### 💡 Exemplo

Um fornecedor deveria entregar um equipamento em 30 dias.

No 25º dia, o responsável verifica:

- Situação da entrega;
- Prazo previsto;
- Possíveis problemas;
- Documentação;
- Condições de recebimento.

---

# 1️⃣7️⃣ Avaliação do fornecedor

O desempenho do fornecedor pode ser acompanhado durante a execução.

### 📊 Indicadores

| Indicador | O que avalia |
|---|---|
| 📅 Prazo | Cumprimento das datas |
| ⭐ Qualidade | Conformidade das entregas |
| 💰 Custo | Cumprimento financeiro |
| 📦 Entregas | Atendimento ao escopo |
| 📞 Suporte | Capacidade de atendimento |
| ⚠️ Problemas | Ocorrências durante o contrato |

### 💡 Exemplo

Um fornecedor entrega regularmente com atraso.

Essa informação deve ser registrada e considerada no gerenciamento do contrato.

---

# 1️⃣8️⃣ Mudanças nos contratos

Durante um projeto, pode ser necessário alterar uma aquisição.

Uma mudança pode ocorrer por:

- 📋 Novo requisito;
- 📦 Alteração do escopo;
- 📅 Mudança de prazo;
- 💰 Alteração de preço;
- ⚠️ Problema técnico;
- ⚖️ Alteração de legislação.

### 🔄 Processo simplificado

**Solicitação**

↓

**Análise**

↓

**Negociação**

↓

**Aprovação**

↓

**Alteração contratual**

↓

**Execução**

---

# 1️⃣9️⃣ Riscos nas aquisições

As aquisições podem apresentar diversos riscos.

### ⚠️ Exemplos

| Risco | Possível impacto |
|---|---|
| 📅 Atraso | Atraso do projeto |
| 💰 Aumento de preço | Aumento do orçamento |
| 📦 Produto inadequado | Retrabalho |
| ⭐ Baixa qualidade | Problemas nas entregas |
| 🏢 Falência do fornecedor | Interrupção |
| 🔄 Mudança contratual | Impacto em custos e prazo |

### 💡 Exemplo

Se um fornecedor atrasar uma entrega crítica:

**Atraso do fornecedor**

↓

**Atividade não inicia**

↓

**Cronograma é afetado**

↓

**Possível aumento de custos**

↓

**Entrega atrasada**

Por isso, os riscos de fornecedores devem ser acompanhados.

# 2️⃣0️⃣ Encerramento das aquisições

Uma aquisição precisa ser encerrada formalmente após a conclusão do trabalho.

### 🏁 Atividades

- 📦 Confirmar entrega;
- 🔎 Verificar requisitos;
- ⭐ Validar qualidade;
- 💳 Realizar pagamentos finais;
- 📑 Organizar documentos;
- 📝 Registrar resultados;
- ⚠️ Resolver pendências;
- 🏁 Encerrar contrato.

### 💡 Exemplo

Após a entrega de um sistema:

| Verificação | Resultado |
|---|---|
| 📦 Entrega | Sistema recebido |
| 🧪 Testes | Concluídos |
| ⭐ Aceite | Aprovado |
| 💳 Pagamento | Finalizado |
| 📑 Documentação | Arquivada |
| 🏁 Contrato | Encerrado |

# 2️⃣2️⃣ Aquisições e outras áreas

### 📊 Relação

| Área | Relação com aquisições |
|---|---|
| 📦 Escopo | Define o que será contratado |
| 📅 Cronograma | Define quando será necessário |
| 💰 Custos | Define orçamento disponível |
| ⭐ Qualidade | Define critérios de aceitação |
| 👥 Recursos | Define o que será interno ou externo |
| 💬 Comunicação | Mantém fornecedor e equipe alinhados |
| ⚠️ Riscos | Avalia riscos de fornecedores |
| 👥 Stakeholders | Considera necessidades e expectativas |

### 💡 Exemplo

Uma contratação atrasada pode afetar:

**Aquisição**

↓

**Cronograma**

↓

**Custos**

↓

**Recursos**

↓

**Qualidade**

↓

**Entrega**

Por isso, aquisições precisam ser gerenciadas de forma integrada.

- 📋 Identificar necessidades;
- 🔎 Apoiar a seleção de fornecedores;
- 📊 Avaliar propostas;
- 🤝 Apoiar negociações;
- 📝 Acompanhar contratos;
- 📦 Verificar entregas;
- ⭐ Acompanhar qualidade;
- ⚠️ Monitorar riscos;
- 💬 Comunicar fornecedores e stakeholders;
- 🏁 Apoiar o encerramento.

> **Gerenciar aquisições significa garantir que produtos e serviços externos contribuam para os objetivos do projeto.**

# 🧠 2️⃣5️⃣ Para lembrar

> **Aquisições permitem obter externamente produtos, serviços ou resultados necessários ao projeto.**

> **Nem tudo precisa ser produzido internamente; a organização pode avaliar se deve fazer ou comprar.**

> **Preço não deve ser o único critério utilizado para selecionar um fornecedor.**

> **O contrato define condições, responsabilidades, prazos, valores e entregas.**

> **Depois da contratação, o fornecedor precisa ser acompanhado durante toda a execução.**

> **Atrasos ou problemas de fornecedores podem afetar custos, prazos, qualidade e escopo.**

> **Uma aquisição somente deve ser encerrada após verificar as entregas, resolver pendências e finalizar as obrigações contratuais.**

> **Gerenciar aquisições significa garantir que os recursos externos necessários contribuam para os objetivos do projeto.**
