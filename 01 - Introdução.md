# 1️⃣ O que é um projeto?

Um **projeto** é um esforço temporário realizado para criar um produto, serviço ou resultado único.

Duas características são fundamentais:

- ⏱️ **Temporário:** possui início e fim.
- 🎯 **Único:** produz um resultado específico.

Um projeto pode durar algumas semanas, meses ou até anos. O importante é que exista um objetivo e uma previsão de encerramento.

### 💡 Exemplos

| Projeto | Resultado |
|---|---|
| 🏠 Construção de uma casa | Casa construída |
| 📱 Desenvolvimento de aplicativo | Aplicativo funcional |
| 🌐 Criação de um site | Website publicado |
| 🎓 Organização de um evento | Evento realizado |
| 🏢 Implantação de sistema | Sistema implantado |
| 🔧 Modernização de laboratório | Laboratório modernizado |

### 📋 Projeto na prática

Um projeto normalmente envolve:

| Elemento | Pergunta |
|---|---|
| 🎯 Objetivo | O que queremos alcançar? |
| 📦 Entregas | O que será produzido? |
| 👥 Pessoas | Quem realizará o trabalho? |
| 📅 Prazo | Quando deverá terminar? |
| 💰 Recursos | Quanto será necessário? |
| ⚠️ Riscos | O que pode dar errado? |

# 2️⃣ Projetos, programas e portfólios

Projetos podem fazer parte de estruturas maiores de gerenciamento.

### 📌 Projeto

É um esforço temporário criado para produzir um resultado único.

### 📦 Programa

É um grupo de projetos relacionados, gerenciados de maneira coordenada para obter benefícios que não seriam obtidos com o gerenciamento individual dos projetos.

### 🗃️ Portfólio

É uma coleção de projetos e programas agrupados para facilitar o gerenciamento e contribuir para os objetivos estratégicos da organização.

### 📊 Comparação

| Estrutura | Principal característica |
|---|---|
| 📌 Projeto | Produz um resultado específico |
| 📦 Programa | Coordena projetos relacionados |
| 🗃️ Portfólio | Organiza projetos e programas de forma estratégica |

### 💡 Exemplo

Uma instituição deseja realizar uma **transformação digital**.

| Nível | Exemplo |
|---|---|
| 🗃️ Portfólio | Portfólio de Tecnologia |
| 📦 Programa | Programa de Transformação Digital |
| 📌 Projeto | Desenvolvimento de novo aplicativo |
| 📌 Projeto | Implantação de novo sistema |
| 📌 Projeto | Automação de processos |

> **Projeto entrega um resultado. Programa coordena projetos. Portfólio organiza iniciativas de forma estratégica.**

---

# 3️⃣ O que é gerenciamento de projetos?

O **gerenciamento de projetos** envolve a aplicação de conhecimentos, habilidades, ferramentas e técnicas às atividades do projeto para atender aos seus requisitos.

Na prática, significa organizar e coordenar o trabalho necessário para alcançar os objetivos definidos.

### 🔄 Principais atividades

| Atividade | Finalidade |
|---|---|
| 📋 Planejamento | Definir como o projeto será realizado |
| ⚙️ Execução | Realizar o trabalho planejado |
| 📊 Monitoramento | Acompanhar o progresso |
| 🔎 Controle | Identificar e tratar desvios |
| 📦 Entrega | Produzir os resultados |
| 🏁 Encerramento | Finalizar formalmente o projeto |

O gerenciamento ajuda a equipe a compreender:

- O que precisa ser realizado;
- Quem será responsável;
- Quando as atividades devem acontecer;
- Quais recursos serão necessários;
- Quais riscos podem ocorrer;
- Como os resultados serão acompanhados.

# 4️⃣ Gerenciamento de projetos e estratégia organizacional

Os projetos não devem existir de maneira isolada.

Eles podem ser utilizados para transformar os objetivos estratégicos da organização em resultados concretos.

### 🎯 Relação com a estratégia

| Nível | Função |
|---|---|
| Estratégia | Define a direção da organização |
| Objetivos | Determinam o que deve ser alcançado |
| Portfólio | Organiza e prioriza iniciativas |
| Programas | Coordena projetos relacionados |
| Projetos | Produzem entregas e resultados |
| Benefícios | Geram resultados para a organização |
| Valor | Representa os benefícios obtidos |

### 💡 Exemplo

**Objetivo estratégico:** aumentar a presença digital da organização.

Possíveis projetos:

- Desenvolvimento de um novo site;
- Criação de aplicativo;
- Automação de processos;
- Implantação de CRM;
- Desenvolvimento de uma plataforma digital.

Cada projeto contribui para alcançar um objetivo maior.

# 5️⃣ Gerenciamento de programas

O gerenciamento de programas busca coordenar projetos relacionados para alcançar benefícios e objetivos comuns.

### 💡 Exemplo

**Programa: Modernização Acadêmica**

| Projeto | Resultado |
|---|---|
| Projeto 1 | Novo ambiente virtual |
| Projeto 2 | Biblioteca digital |
| Projeto 3 | Modernização dos laboratórios |
| Projeto 4 | Capacitação docente |

Os projetos possuem entregas próprias, mas são coordenados dentro de uma visão mais ampla.

### 📊 Projeto × Programa

| Projeto | Programa |
|---|---|
| Objetivo específico | Objetivo mais amplo |
| Produz uma entrega | Coordena diferentes entregas |
| Gerenciamento individual | Gerenciamento coordenado |
| Busca um resultado específico | Busca benefícios integrados |

---

# 6️⃣ Gerenciamento de portfólios

O gerenciamento de portfólios está relacionado à seleção, priorização e acompanhamento de projetos e programas de acordo com os objetivos da organização.

Nem todas as propostas precisam ser executadas.

A organização pode avaliar:

- Alinhamento estratégico;
- Valor esperado;
- Recursos disponíveis;
- Custos;
- Riscos;
- Prioridade;
- Capacidade de execução.

### 💡 Exemplo

Uma empresa possui dez propostas, mas recursos para executar apenas quatro.

| Etapa | Ação |
|---|---|
| 1️⃣ | Receber propostas |
| 2️⃣ | Avaliar iniciativas |
| 3️⃣ | Comparar benefícios |
| 4️⃣ | Avaliar recursos e riscos |
| 5️⃣ | Priorizar projetos |
| 6️⃣ | Selecionar iniciativas |
| 7️⃣ | Acompanhar resultados |

---

# 7️⃣ Projetos e planejamento estratégico

O planejamento estratégico define a direção que a organização deseja seguir.

Os projetos podem transformar essa direção em ações concretas.

### 💡 Exemplo

**Estratégia:** tornar a organização mais digital.

| Iniciativa | Contribuição |
|---|---|
| Novo aplicativo | Melhorar o relacionamento com clientes |
| Automação | Reduzir atividades manuais |
| CRM | Melhorar o relacionamento comercial |
| Novo site | Ampliar a presença digital |

> Projetos são instrumentos utilizados para transformar objetivos estratégicos em resultados.

# 8️⃣ Escritório de Gerenciamento de Projetos — PMO

O **Escritório de Gerenciamento de Projetos (PMO)** é uma estrutura organizacional que pode apoiar o gerenciamento de projetos, programas e portfólios.

Suas funções podem variar de acordo com a organização.

### 📋 Possíveis funções

- Definir padrões;
- Disponibilizar metodologias;
- Criar modelos de documentos;
- Apoiar gerentes de projetos;
- Consolidar informações;
- Acompanhar indicadores;
- Apoiar a governança;
- Compartilhar boas práticas;
- Apoiar processos de decisão.

### 💡 Exemplo

Uma organização possui vários projetos simultâneos.

O PMO pode estabelecer:

| Elemento | Exemplo |
|---|---|
| 📋 Metodologia | Processo padrão de gerenciamento |
| 📄 Documentos | Modelos de TAP e relatórios |
| 📊 Indicadores | Prazo, custo e progresso |
| 📚 Conhecimento | Boas práticas e lições aprendidas |
| 🎯 Governança | Regras para acompanhamento |

# 9️⃣ Projetos e operações

Projetos e operações possuem características diferentes, mas podem trabalhar em conjunto.

### 📊 Comparação

| Projetos | Operações |
|---|---|
| Temporários | Contínuas |
| Possuem início e fim | Não possuem encerramento previsto |
| Produzem resultados únicos | Produzem atividades recorrentes |
| Criam mudanças | Mantêm o funcionamento |
| Possuem objetivo específico | Mantêm processos organizacionais |

### 💡 Exemplo

Uma empresa possui uma plataforma de vendas.

**Projeto:** desenvolver uma nova plataforma.

**Operação:** utilizar a plataforma diariamente para atender clientes e processar pedidos.

Após o término do projeto, o resultado produzido pode passar a fazer parte das operações da organização.

Alguns fatores importantes são:

- 📋 Processos;
- 💬 Comunicação;

- 👔 Liderança;

# 1️⃣1️⃣ Valor de negócio

Um projeto não deve ser avaliado somente pela entrega produzida.

É importante considerar os **benefícios e o valor gerado** para a organização e seus stakeholders.

### 📊 Exemplos

| Projeto | Entrega | Possível valor |
|---|---|---|
| 📱 Aplicativo | Aplicativo funcional | Aumento das vendas |
| 🤖 Automação | Processo automatizado | Redução de custos |
| 🌐 Website | Novo site | Maior alcance |
| 🏭 Nova fábrica | Instalação | Aumento da produção |
| 🔐 Segurança | Sistema de proteção | Redução de riscos |

### 🧠 Conceito-chave

> **A entrega é aquilo que o projeto produz. O valor está relacionado aos benefícios obtidos a partir dessa entrega.**

# 1️⃣2️⃣ Papel do gerente de projetos

O **gerente de projetos** é responsável por liderar e coordenar o projeto para alcançar seus objetivos.

Seu trabalho vai muito além de acompanhar tarefas.

Ele precisa lidar com:

- Pessoas;
- Processos;
- Recursos;
- Comunicação;
- Riscos;
- Prazos;
- Custos;
- Stakeholders;
- Entregas;
- Mudanças.

### 👤 Principais responsabilidades

| Responsabilidade | Objetivo |
|---|---|
| 📋 Planejar | Organizar o trabalho |
| 👥 Liderar | Conduzir a equipe |
| 📅 Acompanhar | Controlar prazos |
| 💰 Gerenciar custos | Controlar recursos financeiros |
| ⚠️ Gerenciar riscos | Antecipar problemas |
| 💬 Comunicar | Compartilhar informações |
| 🤝 Gerenciar stakeholders | Alinhar interesses |
| 🔄 Gerenciar mudanças | Avaliar impactos |
| 📦 Acompanhar entregas | Garantir resultados |

# 1️⃣4️⃣ Habilidades interpessoais

O gerente de projetos trabalha constantemente com pessoas.

Por isso, habilidades interpessoais são fundamentais.

### 🤝 Principais habilidades

- Comunicação;
- Liderança;
- Escuta ativa;
- Empatia;
- Negociação;
- Resolução de conflitos;
- Trabalho em equipe;
- Influência;
- Tomada de decisão.

### 💡 Exemplo

Dois integrantes da equipe discordam sobre uma solução.

O gerente pode:

1. Ouvir as partes;
2. Entender o problema;
3. Identificar alternativas;
4. Avaliar os impactos;
5. Tomar uma decisão;
6. Comunicar a decisão à equipe.

# 1️⃣5️⃣ Conhecimento em gerenciamento de projetos

O gerenciamento de projetos envolve diferentes conhecimentos.

Um gerente deve compreender aspectos como:

- Escopo;
- Cronograma;
- Custos;
- Qualidade;
- Recursos;
- Comunicação;
- Riscos;
- Aquisições;
- Stakeholders;
- Integração.

Esses conhecimentos estão relacionados.

Uma alteração no escopo, por exemplo, pode afetar o cronograma, os custos, os recursos e os riscos.

### 🧩 Exemplo

| Mudança | Possíveis impactos |
|---|---|
| Novo requisito | Aumento do escopo |
| Aumento do escopo | Mais trabalho |
| Mais trabalho | Maior duração |
| Maior duração | Possível aumento de custos |
| Mais recursos | Novos riscos e necessidades |

Por isso, o gerente precisa analisar o projeto de maneira integrada.
