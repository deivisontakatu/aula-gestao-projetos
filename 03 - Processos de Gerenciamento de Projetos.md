# 1️⃣ Processos de gerenciamento de projetos

Os processos de gerenciamento de projetos são utilizados para organizar e conduzir as atividades necessárias para alcançar os objetivos do projeto.

Eles permitem estruturar o trabalho e estabelecer uma forma organizada de:

- Iniciar o projeto;
- Planejar as atividades;
- Executar o trabalho;
- Acompanhar os resultados;
- Controlar mudanças;
- Encerrar o projeto.

Os processos não devem ser vistos como atividades completamente isoladas. Eles possuem relações e interações ao longo do projeto.

---

# 2️⃣ Interações entre processos

Os processos de gerenciamento de projetos interagem entre si.

Uma informação produzida em determinado processo pode ser utilizada posteriormente por outro processo.

### 💡 Exemplo

Durante o planejamento, a equipe pode definir uma estimativa de prazo.

Durante o monitoramento, essa informação será utilizada para comparar o progresso real com o planejamento.

| Processo | Informação |
|---|---|
| 📋 Planejamento | Prazo planejado |
| ⚙️ Execução | Trabalho realizado |
| 📊 Monitoramento | Comparação entre planejado e realizado |
| 🔄 Controle | Ações corretivas ou mudanças |

Essa interação permite que o projeto seja acompanhado e ajustado durante sua execução.

---

# 3️⃣ Grupos de processos de gerenciamento

Os processos são organizados em cinco grupos principais:

| Grupo | Finalidade |
|---|---|
| 🚀 Iniciação | Definir e autorizar o projeto |
| 📋 Planejamento | Definir objetivos e como o trabalho será realizado |
| ⚙️ Execução | Realizar o trabalho planejado |
| 📊 Monitoramento e controle | Acompanhar, analisar e controlar o projeto |
| 🏁 Encerramento | Finalizar formalmente o projeto |

### 🧠 Importante

Os grupos de processos **não representam necessariamente fases do projeto**.

Eles representam conjuntos de processos utilizados para gerenciar o projeto.

Um projeto pode utilizar processos de monitoramento e controle durante diferentes momentos de sua execução.

---

# 4️⃣ Grupo de processos de iniciação

A iniciação está relacionada ao início formal do projeto ou de uma fase do projeto.

Nesse momento, busca-se estabelecer uma compreensão inicial sobre:

- Por que o projeto será realizado;
- Qual problema será resolvido;
- Qual resultado é esperado;
- Quem são os principais envolvidos;
- Quais são as principais restrições.

### 🎯 Principais objetivos

| Objetivo | Descrição |
|---|---|
| 🎯 Definir propósito | Entender por que o projeto existe |
| 📌 Definir objetivos | Estabelecer o que se pretende alcançar |
| 👥 Identificar envolvidos | Reconhecer as principais partes interessadas |
| 🏛️ Obter autorização | Formalizar o início do projeto |
| 📋 Estabelecer informações iniciais | Criar uma base para o planejamento |

---

# 5️⃣ Grupo de processos de planejamento

O planejamento busca definir como o projeto será realizado.

É nesse momento que a equipe desenvolve e detalha informações relacionadas ao trabalho.

### 📋 Elementos importantes

- Escopo;
- Cronograma;
- Custos;
- Recursos;
- Qualidade;
- Comunicação;
- Riscos;
- Aquisições;
- Stakeholders.

### 💡 Exemplo

Para um projeto de desenvolvimento de um aplicativo, o planejamento pode definir:

| Elemento | Exemplo |
|---|---|
| 🎯 Objetivo | Criar aplicativo de vendas |
| 📦 Escopo | Funcionalidades previstas |
| 📅 Cronograma | 4 meses |
| 👥 Equipe | Desenvolvedores, designer e analista |
| 💰 Custo | Orçamento definido |
| ⚠️ Riscos | Atrasos e problemas técnicos |
| ⭐ Qualidade | Critérios de aceitação |

> O planejamento cria uma referência para orientar a execução e acompanhar o desempenho do projeto.

---

# 6️⃣ Grupo de processos de execução

A execução corresponde à realização do trabalho definido no planejamento.

Nesse grupo, a equipe utiliza os recursos disponíveis para produzir as entregas do projeto.

### ⚙️ Exemplos de atividades

- Desenvolver produtos;
- Realizar reuniões;
- Gerenciar a equipe;
- Executar atividades técnicas;
- Realizar aquisições;
- Produzir entregas;
- Gerenciar comunicações;
- Implementar respostas aos riscos.

### 💡 Exemplo

Em um projeto de software:

| Atividade | Execução |
|---|---|
| Análise | Levantamento das necessidades |
| Design | Criação das interfaces |
| Desenvolvimento | Implementação do sistema |
| Testes | Verificação das funcionalidades |
| Implantação | Disponibilização da solução |

---

# 7️⃣ Grupo de processos de monitoramento e controle

O monitoramento e controle permite acompanhar o desempenho do projeto e verificar se o trabalho está seguindo o que foi planejado.

### 📊 O que pode ser acompanhado?

- Prazo;
- Custos;
- Escopo;
- Qualidade;
- Riscos;
- Recursos;
- Entregas;
- Mudanças.

### 💡 Exemplo

| Indicador | Planejado | Realizado | Situação |
|---|---:|---:|---|
| 📅 Prazo | 30 dias | 35 dias | ⚠️ Atraso |
| 💰 Custo | R$ 10.000 | R$ 9.500 | ✅ Dentro do orçamento |
| 📦 Entregas | 10 | 8 | ⚠️ Em andamento |
| ⭐ Qualidade | 95% | 97% | ✅ Acima da meta |

Quando são identificados desvios, podem ser necessárias ações corretivas ou mudanças.

---

# 8️⃣ Controle de mudanças

Durante um projeto, mudanças podem ser necessárias.

Uma mudança pode ocorrer por diferentes motivos:

- Nova necessidade do cliente;
- Alteração de requisito;
- Problema técnico;
- Mudança de legislação;
- Alteração de orçamento;
- Mudança de prioridade.

As mudanças devem ser analisadas antes de serem implementadas.

### 🔄 Processo simplificado

| Etapa | Ação |
|---|---|
| 1️⃣ | Solicitar mudança |
| 2️⃣ | Analisar impacto |
| 3️⃣ | Avaliar alternativas |
| 4️⃣ | Aprovar ou rejeitar |
| 5️⃣ | Atualizar informações |
| 6️⃣ | Implementar mudança |
| 7️⃣ | Acompanhar resultado |

> Uma mudança aparentemente pequena pode afetar prazo, custo, escopo, qualidade e riscos.

---

# 9️⃣ Grupo de processos de encerramento

O encerramento representa a finalização formal do projeto ou de uma fase.

Nesse momento, é importante verificar se as atividades foram concluídas e se as entregas foram aceitas.

### 🏁 Atividades

- Confirmar conclusão;
- Obter aceite das entregas;
- Finalizar contratos;
- Organizar documentos;
- Registrar lições aprendidas;
- Liberar recursos;
- Arquivar informações;
- Encerrar formalmente o projeto.

### 💡 Exemplo

Após a implantação de um sistema:

| Atividade | Resultado |
|---|---|
| Entrega | Sistema disponibilizado |
| Aceite | Cliente aprova |
| Documentação | Informações organizadas |
| Lições aprendidas | Conhecimentos registrados |
| Recursos | Equipe liberada |
| Encerramento | Projeto formalmente finalizado |

# 🔟 Informações do projeto

Durante o gerenciamento, diferentes tipos de informações são produzidos e utilizados.

Essas informações ajudam a equipe e os responsáveis pelo projeto a tomar decisões.

### 📊 Exemplos

| Informação | Utilização |
|---|---|
| 📅 Cronograma | Acompanhar prazos |
| 💰 Custos | Controlar orçamento |
| 📦 Entregas | Acompanhar resultados |
| ⚠️ Riscos | Avaliar ameaças e oportunidades |
| 🔄 Mudanças | Controlar alterações |
| 📊 Indicadores | Avaliar desempenho |
| 📝 Relatórios | Comunicar situação do projeto |

As informações precisam ser organizadas e disponibilizadas para as pessoas que necessitam delas.

---

# 1️⃣1️⃣ Dados, informações e relatórios

Durante o projeto, os dados podem ser transformados em informações úteis para tomada de decisão.

### 📊 Exemplo

**Dado:**

> 80 horas trabalhadas.

**Informação:**

> A equipe utilizou 20% mais horas do que o planejado.

**Relatório:**

> O projeto apresenta aumento de esforço e pode sofrer impacto no prazo.

Esse processo permite transformar dados operacionais em informações úteis para gerenciamento.

# 1️⃣2️⃣ Áreas de conhecimento

O gerenciamento de projetos envolve diferentes áreas de conhecimento.

Cada área possui objetivos e práticas específicas, mas elas precisam ser integradas.

### 📚 Principais áreas

| Área | Foco |
|---|---|
| 🔗 Integração | Coordenar e integrar o projeto |
| 📦 Escopo | Definir o trabalho necessário |
| 📅 Cronograma | Gerenciar o tempo |
| 💰 Custos | Gerenciar recursos financeiros |
| ⭐ Qualidade | Garantir requisitos e padrões |
| 👥 Recursos | Gerenciar pessoas e recursos |
| 💬 Comunicações | Gerenciar informações |
| ⚠️ Riscos | Gerenciar incertezas |
| 🛒 Aquisições | Gerenciar compras e fornecedores |
| 👥 Stakeholders | Gerenciar partes interessadas |

---

# 1️⃣3️⃣ Integração entre áreas

As áreas de conhecimento não devem ser gerenciadas de maneira completamente isolada.

Uma alteração em uma área pode afetar outras.

### 💡 Exemplo

Um cliente solicita uma nova funcionalidade.

| Área | Possível impacto |
|---|---|
| 📦 Escopo | Aumento do trabalho |
| 📅 Cronograma | Aumento do prazo |
| 💰 Custos | Aumento dos custos |
| 👥 Recursos | Necessidade de profissionais |
| ⚠️ Riscos | Novos riscos |
| ⭐ Qualidade | Novos critérios de teste |
| 💬 Comunicação | Necessidade de informar stakeholders |

Por isso, a integração é fundamental para avaliar o impacto das decisões.

---

# 1️⃣4️⃣ Integração do projeto

A **integração** busca coordenar os diferentes elementos do projeto.

O gerente de projetos precisa compreender como as decisões de uma área podem afetar o restante do projeto.

### 🧠 Exemplo

Uma mudança no escopo pode gerar:

**Novo requisito**

↓  

**Mais trabalho**

↓  

**Mais tempo**

↓  

**Mais recursos**

↓  

**Possível aumento de custos**

↓  

**Novos riscos**

Essa visão integrada ajuda a evitar decisões isoladas.
