# 1️⃣ O que é gerenciamento de custos?

O **gerenciamento de custos** envolve os processos utilizados para planejar, estimar, determinar e controlar os custos de um projeto.

Seu objetivo é permitir que o projeto seja realizado considerando os recursos financeiros disponíveis e o orçamento estabelecido.

### 💰 Principais atividades

| Atividade | Finalidade |
|---|---|
| 📋 Planejamento | Definir como os custos serão gerenciados |
| 🧮 Estimativa | Estimar os custos necessários |
| 💰 Orçamento | Consolidar os custos previstos |
| 📊 Monitoramento | Acompanhar os custos realizados |
| 🔎 Controle | Identificar e tratar desvios |

### 💡 Exemplo

Um projeto de desenvolvimento de um aplicativo pode envolver:

- 👨‍💻 Desenvolvedores;
- 🎨 Designer;
- ☁️ Infraestrutura;
- 💻 Software e ferramentas;
- 🖥️ Equipamentos;
- 🛒 Serviços contratados;
- 📢 Divulgação.

Todos esses elementos podem representar custos para o projeto.

---

# 2️⃣ Planejamento dos custos

O planejamento dos custos define **como os custos do projeto serão estimados, registrados, acompanhados e controlados**.

Antes de iniciar o trabalho, a equipe precisa estabelecer uma forma organizada para gerenciar os recursos financeiros.

### 📋 Perguntas importantes

- Quanto o projeto deverá custar?
- Quais recursos serão necessários?
- Como os custos serão estimados?
- Quem será responsável pelo acompanhamento?
- Como os gastos serão registrados?
- Como serão tratadas as variações?
- Qual orçamento está disponível?

### 💡 Exemplo

Em um projeto de desenvolvimento de sistema:

| Recurso | Necessidade |
|---|---|
| 👨‍💻 Desenvolvedores | Desenvolvimento |
| 🎨 Designer | Interface |
| ☁️ Servidor | Hospedagem |
| 💻 Software | Ferramentas |
| 🧪 Testes | Validação |
| 🛒 Serviços | Recursos externos |

O planejamento permite identificar esses elementos antes da execução.

# 3️⃣ Tipos de custos

Os custos de um projeto podem ser classificados de diferentes maneiras.

Essa classificação ajuda a equipe a compreender onde os recursos financeiros serão utilizados.

### 📊 Custos diretos e indiretos

| Tipo | Característica | Exemplo |
|---|---|---|
| 💰 Direto | Relacionado diretamente ao projeto | Salário da equipe do projeto |
| 🏢 Indireto | Apoia o projeto, mas não está diretamente associado a uma entrega | Energia e estrutura administrativa |

### 📊 Custos fixos e variáveis

| Tipo | Característica | Exemplo |
|---|---|---|
| 🔒 Fixo | Não varia diretamente com o volume de trabalho | Licença de software |
| 🔄 Variável | Pode variar de acordo com a utilização | Consumo de infraestrutura |

### 💡 Exemplo

Uma empresa desenvolve um aplicativo.

| Custo | Classificação possível |
|---|---|
| Salário do desenvolvedor | Direto |
| Licença de ferramenta | Direto |
| Energia do escritório | Indireto |
| Servidor utilizado | Variável |
| Licença anual | Fixo |

# 4️⃣ Estimativa de custos

A **estimativa de custos** consiste em determinar uma previsão dos recursos financeiros necessários para realizar as atividades do projeto.

As estimativas devem considerar as informações disponíveis e podem ser refinadas conforme o projeto evolui.

### 🧮 Elementos utilizados

- 📋 Escopo;
- 📅 Cronograma;
- 👥 Recursos;
- 🛒 Aquisições;
- 📊 Histórico de projetos;
- ⚠️ Riscos;
- 💰 Preços e valores disponíveis.

### 💡 Exemplo

Uma equipe precisa estimar o custo de desenvolvimento de um sistema.

| Recurso | Quantidade | Valor estimado |
|---|---:|---:|
| 👨‍💻 Desenvolvedor | 160 horas | R$ 16.000 |
| 🎨 Designer | 40 horas | R$ 4.000 |
| 🧪 Testes | 40 horas | R$ 3.000 |
| ☁️ Infraestrutura | 4 meses | R$ 2.000 |
| 🛠️ Ferramentas | 4 meses | R$ 1.000 |
| **Total** | | **R$ 26.000** |

A estimativa representa uma previsão e pode sofrer alterações durante o projeto.

# 5️⃣ Técnicas de estimativa

Existem diferentes formas de realizar estimativas de custos.

A escolha depende das informações disponíveis, do nível de detalhamento e das características do projeto.

### 📊 Principais técnicas

| Técnica | Característica |
|---|---|
| 📚 Análoga | Utiliza projetos anteriores semelhantes |
| 🧮 Paramétrica | Utiliza relações matemáticas ou parâmetros |
| 🔍 Bottom-up | Estima atividades individualmente e depois consolida |
| 👥 Três pontos | Considera diferentes cenários |
| 🧠 Opinião especializada | Utiliza conhecimento de especialistas |

### 💡 Exemplo — estimativa análoga

Um projeto anterior de desenvolvimento de aplicativo custou aproximadamente **R$ 50.000**.

Um novo projeto possui características semelhantes.

A equipe pode utilizar o projeto anterior como referência inicial para sua estimativa.

> **Estimativas anteriores podem fornecer informações importantes para projetos futuros.**

# 6️⃣ Estimativa de três pontos

A estimativa de três pontos considera diferentes cenários para representar as incertezas existentes.

Podem ser considerados:

| Estimativa | Significado |
|---|---|
| 😊 Otimista | Cenário mais favorável |
| 📊 Mais provável | Cenário esperado |
| ⚠️ Pessimista | Cenário mais desfavorável |

Uma forma simples de calcular a estimativa esperada é:

**E = (O + 4M + P) / 6**

Onde:

- **O** = estimativa otimista;
- **M** = estimativa mais provável;
- **P** = estimativa pessimista.

### 💡 Exemplo

Uma atividade possui:

- Otimista = R$ 8.000
- Mais provável = R$ 10.000
- Pessimista = R$ 16.000

Aplicando a fórmula:

**E = (8.000 + 4 × 10.000 + 16.000) / 6**

**E = R$ 10.666,67**

A estimativa esperada é aproximadamente **R$ 10.666,67**.

# 7️⃣ Orçamento do projeto

O **orçamento do projeto** representa a consolidação dos custos estimados necessários para realizar o trabalho planejado.

Ele permite estabelecer uma referência para acompanhar o desempenho financeiro do projeto.

### 💰 Composição simplificada

**Estimativas das atividades**

↓

**Custos dos pacotes de trabalho**

↓

**Custos das entregas**

↓

**Orçamento do projeto**

### 💡 Exemplo

| Categoria | Custo |
|---|---:|
| 👥 Equipe | R$ 40.000 |
| 💻 Tecnologia | R$ 8.000 |
| 🛒 Aquisições | R$ 12.000 |
| ☁️ Infraestrutura | R$ 5.000 |
| 📋 Outros custos | R$ 5.000 |
| **Orçamento** | **R$ 70.000** |

---

# 8️⃣ Linha de base dos custos

A **linha de base dos custos** representa uma referência aprovada para comparação com os custos realizados durante o projeto.

Ela permite verificar se o projeto está gastando conforme o planejamento.

### 📊 Exemplo

| Mês | Planejado | Realizado |
|---|---:|---:|
| Janeiro | R$ 10.000 | R$ 9.500 |
| Fevereiro | R$ 15.000 | R$ 17.000 |
| Março | R$ 20.000 | R$ 18.000 |
| Abril | R$ 25.000 | R$ 27.000 |

A comparação permite identificar períodos em que os gastos ficaram acima ou abaixo do planejado.

> **A linha de base funciona como uma referência para acompanhar o desempenho dos custos.**

---

# 9️⃣ Reservas de custos

Projetos podem apresentar incertezas que podem gerar custos adicionais.

Por isso, podem existir reservas para lidar com determinados riscos e incertezas.

### 💰 Exemplo

Um projeto possui:

**Custo estimado:** R$ 100.000

**Reserva:** R$ 10.000

**Orçamento total:** R$ 110.000

A existência de uma reserva não significa que o valor será necessariamente utilizado.

Ela representa uma forma de considerar determinadas incertezas no planejamento financeiro.

# 🔟 Controle de custos

O **controle de custos** consiste em acompanhar os custos do projeto e identificar possíveis variações em relação ao planejamento.

### 📊 O que pode ser acompanhado?

- 💰 Custos realizados;
- 📋 Custos planejados;
- 📅 Evolução do projeto;
- 📦 Entregas realizadas;
- 👥 Recursos utilizados;
- ⚠️ Variações;
- 🔄 Mudanças aprovadas.

### 💡 Exemplo

| Indicador | Planejado | Realizado | Situação |
|---|---:|---:|---|
| 💰 Custos | R$ 50.000 | R$ 48.000 | ✅ Abaixo |
| 📅 Prazo | 90 dias | 95 dias | ⚠️ Atraso |
| 📦 Entregas | 10 | 8 | ⚠️ Em andamento |

O custo estar abaixo do planejado não significa necessariamente que o projeto esteja em uma situação melhor.

É necessário analisar também o trabalho que foi realizado.

---

# 1️⃣1️⃣ Variação de custos

A variação de custos representa a diferença entre o valor planejado e o valor realizado.

Uma forma simples de representar é:

**Variação = Custo planejado − Custo realizado**

### 💡 Exemplo

Custo planejado:

**R$ 20.000**

Custo realizado:

**R$ 23.000**

Então:

**Variação = 20.000 − 23.000**

**Variação = −R$ 3.000**

Nesse exemplo, o projeto apresentou um custo realizado superior ao planejado.

### 📊 Comparação

| Situação | Resultado |
|---|---|
| Realizado < Planejado | Custo abaixo do previsto |
| Realizado = Planejado | Custo conforme previsto |
| Realizado > Planejado | Custo acima do previsto |

# 1️⃣2️⃣ Custos e desempenho do projeto

O custo não deve ser analisado isoladamente.

É necessário observar a relação entre:

- 💰 Custos;
- 📅 Prazo;
- 📦 Escopo;
- ⭐ Qualidade;
- 👥 Recursos;
- ⚠️ Riscos.

### 💡 Exemplo

Um projeto gastou apenas **R$ 50.000** de um orçamento de **R$ 80.000**.

Inicialmente, isso pode parecer positivo.

Porém, se apenas **50% das entregas** foram concluídas, o custo menor pode estar relacionado ao atraso na execução.

> **O custo precisa ser analisado em conjunto com o trabalho realizado.**

# 1️⃣3️⃣ Gerenciamento do valor agregado

O **gerenciamento do valor agregado** permite comparar o trabalho planejado, o trabalho realizado e os custos utilizados.

Três informações importantes são:

| Sigla | Conceito |
|---|---|
| 📋 PV | Valor planejado |
| 📦 EV | Valor agregado |
| 💰 AC | Custo real |

### 📋 Valor planejado — PV

Representa o valor do trabalho que estava planejado para ser realizado até determinado momento.

### 📦 Valor agregado — EV

Representa o valor do trabalho que efetivamente foi realizado.

### 💰 Custo real — AC

Representa o custo efetivamente realizado.

---

# 1️⃣4️⃣ Exemplo de valor agregado

Um projeto possui orçamento total de **R$ 100.000**.

Após determinado período:

- **PV = R$ 60.000**
- **EV = R$ 50.000**
- **AC = R$ 55.000**

Podemos observar:

| Indicador | Valor |
|---|---:|
| 📋 Planejado (PV) | R$ 60.000 |
| 📦 Realizado em valor (EV) | R$ 50.000 |
| 💰 Custo real (AC) | R$ 55.000 |

O projeto realizou menos trabalho do que estava planejado e gastou mais do que o valor correspondente ao trabalho realizado.

### 🧠 Interpretação

**PV > EV**

→ Foi realizado menos trabalho do que o planejado.

**AC > EV**

→ O custo realizado foi maior que o valor do trabalho realizado.

---

# 1️⃣5️⃣ Índices de desempenho

Os valores agregados podem ser utilizados para calcular indicadores de desempenho.

### 💰 Índice de desempenho de custos — CPI

**CPI = EV / AC**

### 📅 Índice de desempenho de prazo — SPI

**SPI = EV / PV**

### 💡 Exemplo

Considerando:

- EV = R$ 50.000
- AC = R$ 55.000
- PV = R$ 60.000

Temos:

**CPI = 50.000 / 55.000**

**CPI ≈ 0,91**

E:

**SPI = 50.000 / 60.000**

**SPI ≈ 0,83**

Esses indicadores permitem analisar o desempenho de custos e prazo em relação ao planejamento.

# 1️⃣6️⃣ Custos e mudanças no projeto

Mudanças no projeto podem gerar impactos financeiros.

Uma alteração aparentemente pequena pode aumentar o trabalho necessário e gerar novos custos.

### 💡 Exemplo

O cliente solicita uma nova funcionalidade.

| Área | Possível impacto |
|---|---|
| 📦 Escopo | Novo requisito |
| 👥 Recursos | Mais profissionais |
| 📅 Cronograma | Aumento do prazo |
| 💰 Custos | Aumento do orçamento |
| 🧪 Qualidade | Novos testes |
| ⚠️ Riscos | Novas incertezas |

Por isso, mudanças devem ser analisadas antes de serem implementadas.

# 1️⃣7️⃣ Integração entre custos e outras áreas

O gerenciamento de custos está diretamente relacionado às demais áreas do projeto.

### 🧩 Exemplo

Uma alteração no escopo pode gerar:

**Novo requisito**

↓

**Mais trabalho**

↓

**Mais recursos**

↓

**Maior duração**

↓

**Aumento dos custos**

↓

**Novos riscos**

Essa relação demonstra a importância de analisar o projeto de maneira integrada.

# 1️⃣8️⃣ Custos ao longo do projeto

Os custos podem variar ao longo do ciclo de vida do projeto.

### 📊 Exemplo

| Fase | Possíveis custos |
|---|---|
| 🚀 Iniciação | Estudos e análises iniciais |
| 📋 Planejamento | Estimativas e planejamento |
| ⚙️ Execução | Equipe, materiais e serviços |
| 📊 Monitoramento | Controle e acompanhamento |

A distribuição dos custos depende das características de cada projeto.

# 1️⃣9️⃣ Exemplo completo

Uma empresa deseja desenvolver um sistema para atendimento de clientes.

O projeto possui o seguinte orçamento:

| Categoria | Valor |
|---|---:|
| 👨‍💻 Desenvolvimento | R$ 40.000 |
| 🎨 Design | R$ 8.000 |
| 🧪 Testes | R$ 7.000 |

Durante a execução, os custos foram acompanhados mensalmente.

| Mês | Planejado | Realizado |
|---|---:|---:|
| 1 | R$ 15.000 | R$ 14.000 |
| 2 | R$ 20.000 | R$ 22.000 |
| 3 | R$ 20.000 | R$ 21.000 |

### 📊 Análise

O projeto apresentou custos superiores ao planejamento em determinados períodos.

O gerente de projetos deve investigar:

- O que provocou o aumento?
- Houve mudança de escopo?
- Houve aumento de recursos?
- Alguma atividade demorou mais?
- Algum fornecedor apresentou aumento?
- Existem riscos relacionados aos custos?
- O orçamento precisa ser revisado?

# 2️⃣0️⃣ Papel do gerente de projetos nos custos

O gerente de projetos precisa acompanhar os custos durante todo o projeto.

Seu trabalho inclui:

- 📋 Planejar os custos;
- 🧮 Apoiar as estimativas;
- 💰 Acompanhar o orçamento;
- 📊 Analisar variações;
- ⚠️ Identificar riscos financeiros;
- 🔄 Avaliar impactos de mudanças;
- 💬 Comunicar informações;
- 📈 Acompanhar indicadores;
- 🤝 Apoiar decisões;
- 🎯 Manter o projeto alinhado aos objetivos.

### 👤 Exemplo

Se o projeto apresenta aumento de custos, o gerente deve analisar a situação antes de tomar uma decisão.

Ele pode avaliar:

1. O motivo da variação;
2. O impacto no orçamento;
3. O impacto no prazo;
4. O impacto no escopo;
5. Alternativas disponíveis;
6. Necessidade de mudança;
7. Comunicação aos stakeholders.
